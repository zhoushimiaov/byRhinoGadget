LookAtSetBlock

 LookAtSetBlock : 선택한 개체를 LookAt 개체 블록으로 설정합니다.

Steps

1.  LookAtSetBlock 실행

2.  LookAt 개체 블록으로 변환할 개체 선택

3.  LookAt 개체 블록으로 변환할 개체의 중심점 선택

4.  LookAt 개체 이름 입력

 

 

Note

▷  설정 후 목록에서 선택 가능합니다.

▷  Alpha 채널이 있는 이미지 Picture로 Import후 사용 시 효과적입니다.

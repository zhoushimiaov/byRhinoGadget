RevCloudsBySketch

 RevCloudsBySketch : 영역을 그려 말 풍선 모양 커브를 자동으로 생성합니다.

Steps

1.  RevCloudsBySketch 실행

2.  구름 형상의 간격 입력

3.  영역을 그려 커브 생성(시계 방향 - 음각/반시계 방향 - 양각)

 

  

Option

▷  Main Option

•     Distance
스케치 커브를 나누는 거리 값

•     Angle

구름 형상을 이루는 커브간 각도

▷  Output

•     Closed
Yes - 닫힌 커브 생성 / No – 열린 커브 생성

•     On Surface
선택 시 서피스 위에 스케치 커브 생성

•     On Mesh
선택 시 메시 위에 스케치 커브 생성

•     Click To Sketch

선택 시 메시 위에 스케치 커브 생성

Note

▷  구름표시는 도면에 수정 사항을 표시할 때 보편적으로 사용합니다.

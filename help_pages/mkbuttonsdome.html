mkButtonsDome

 MkButtonsDome : 선택된 커브의 모양대로 돔 형태의 버튼을 생성합니다.

Steps

1.  MkButtonsDome 실행

2.  버튼을 생성할 커브 선택

3.  버튼을 생성할 서피스 선택

4.  옵션 선택 후 적용

 

  

Option

▷  MoveButton
버튼의 돌출 양 설정

▷  Height
돔 버튼의 높이 설정

▷  Offset
버튼 사이 간격 설정

▷  Direction
버튼 생성 각도 설정

▷  Filp
버튼의 생성 방향 뒤집기

Note

▷  버튼의 형상이 될 커브는 닫힌 상태이어야 합니다.

▷  버튼의 돌출 양, 방향, 버튼 사이 간격 조절 가능합니다.

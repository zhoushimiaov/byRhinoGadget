SlideForward / SlideBackward

 SlideForward /  SlideBackward : Named view에 설정된 뷰로 순차 전환이 가능합니다.

Steps

1.  SlideBackward 또는 SlideForward 실행

2.  Named view에 설정된 순서로 정방향이나 역방향으로 뷰 전환

 

 

Option

▷  Named View Animation Settings
명명된 뷰 애니메이션 설정

▷  Animate named view restoration
명명된 뷰 불러올 때 애니메이션 사용 여부체크

▷  Constant time
일정한 시간 (프레임 숫자↓ 속도↑, 프레임 숫자↑ 속도↓)

▷  Constant speed
일정한 속도 (프레임당 단위↑ 속도↑, 프레임당 단위↓ 속도↓)

▷  Delay between frames
프레임 사이의 지연 (밀리 초↑ 속도↓, 밀리 초↓ 속도↑)

Note

▷  Named view에 뷰 설정 후 사용 가능합니다.

▷  명령어를 단축키 설정 시 프레젠테이션 상황에서 간편하게 사용 가능합니다.

▷  Named view 창이 닫힌 상태에서 명령어 실행 가능합니다.

See Also

FlowMulti

 FlowMulti : 다수의 커브에 Flow 실행합니다.

Steps

1.  FlowMulti 실행

2.  Flow할 개체 선택

3.  기준 커브 선택

4.  옵션 설정

5.  적용할 여러 커브 선택 후 적용

 

  

Option

▷  Copy
Flow 개체 복사

▷  Rigid
Flow 개체의 형태 유지

▷  Stretch
Flow 개체의 형태가 커브를 따라 변형

Note

▷  기존 Flow명령어는 타겟 커브를 하나만 선택 가능하지만 FlowMulti 명령어는 여러 커브에 Flow하는 경우 사용할 수 있습니다.

Examples

▷  Rigid=no / Stretch=yes, Rigid=yes / Stretch=no 설정한 이미지 예시

Randomize

 Randomize : 여러 개체를 랜덤으로 이동, 회전 및 크기를 조절하거나 색상을 변경합니다.

Steps

1.  Randomize 실행

2.  옵션 설정 후 확인

Option

▷  Object transform

•     Move
X, Y, Z 기준 설정한 수치대로 이동

•     Rotate
X, Y, Z 기준 설정한 수치대로 회전

•     Scale
X, Y, Z 기준 설정한 수치대로 크기변형

▷  Point move
X, Y, Z 기준 설정한 수치대로 이동

▷  Display color
설정한 RGB 영역 값만큼 색상을 변경

Note

▷  개체들을 자연스럽게 조금씩 이동시킬 때 편리합니다.

▷  서피스, 커브의 제어점을 무작위로 변형시킬 때 이용합니다.

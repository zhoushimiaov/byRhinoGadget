DimBoundingBox

 DimBoundingBox : 개체 형태에 맞춰 BoundingBox를 생성하고 X, Y, Z 치수를 나타냅니다.

Steps

1.  DimBoundingBox 실행

2.  옵션 설정

3.  대상 개체 선택

Option

▷  Type

•     Dot
치수를 도트에 표시

•     Dimension
선형치수로 표시

•     Value
치수를 별도의 창으로 표시 (텍스트 복사 후, 문서화할 때 유용)

▷  DrawBox

•     Yes
개체의 BoundingBox를 그리며 표시

•     No
개체의 BoundingBox를 그리지 않고 표시

▷  nDigits

•     수치의 소수점 자리
ex) nDigits = 1 / 0.1
ex) nDigits = 2 / 0.01

▷  Orient

•     World
World를 기준평면으로 BoundingBox 생성

•     CPlane
CPlane을 기준평면으로 BoundingBox 생성

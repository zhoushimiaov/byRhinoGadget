SphereDeformable

 SphereDeformable : 제어점 편집이 가능한 구를 생성합니다.

Steps

1.  SphereDeformable 실행

2.  U, V 방향 차수 설정

3.  구의 중심점 선택

4.  지름 입력 또는 기준점 설정하여 구 생성

 

  

Option

▷  Main Option

•     Sphere control points count
구의 UV차수 설정, 재설정

▷  Output

•     Center of sphere
구의 위치 포인트 설정

Note

▷  최저 차수 6입니다.

▷  기준점 설정 시 2Point, 3Point, Tangent, AroundCurve, 4Point, FitPoints 옵션 사용 가능합니다.

▷  구를 동일 조건으로 Rebuild하여 형성할 때 비대칭 점들이 대칭으로 정렬 되어있는 상태입니다.

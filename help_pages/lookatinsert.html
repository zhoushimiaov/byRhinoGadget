LookAtInsert

 LookAtInsert : LookAt 블록 개체를 지정 위치에 생성합니다.

Steps

1.  LookAtInsert 실행

2.  생성할 개체 이름 선택

3.  개체 위치 지정

 

 

Option

▷  Man1, Man2, Man3, Man4, Woman 1, Woman 2, Woman 3
Default LookAt 개체

▷  Random
등록된 LookAt 개체 랜덤으로 생성

Note

▷  LookAtLoadDefault 로드한 기본 LookAt 개체(Man1, Man2, Man3, Man4, Woman 1, Woman 2, Woman 3) 또는 LookAtSetBlock을 통해 등록한 LookAt 개체를 삽입합니다.

▷  Random 배치가 가능합니다.

See also

 LookAt -Insert된 LookAt 블록 개체를 카메라를 향하게 정렬합니다.

 LookAtLoadDefault – 설정된 기본 LookAt 블록 개체를 불러옵니다.

 LookAtParallel – Insert된 LookAt 블록 개체를 투시 없이 카메라를 향하게 정렬합니다.

 LookAtProjectZ - Insert된 LookAt 블록 개체를 지정한 개체 위로 정렬합니다.

 LookAtSel - 선택한 LookAt 개체와 같은 개체를 선택합니다.

 LookAtSelAll - LookAt 개체를 모두 선택합니다.

 LookAtSelName - 이름으로 지정한 LookAt 개체를 모두 선택합니다.

 LookAtSetBlock - 선택한 개체를 LookAt 개체 블록으로 설정합니다.

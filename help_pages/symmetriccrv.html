SymmetricCrv

 SymmetricCrv : 커브의 제어점을 대칭으로 정렬합니다.

Steps

1.  명령 SymmetricCrv 실행

2.  대상 커브 선택

3.  두 점을 입력하여 대칭 축 설정

4.  대칭 방향 선택

 

   

Note

▷  대칭 형상을 중심 축에서 나뉘지 않고 하나의 커브로 그릴 때 사용합니다.

▷  제어점의 개수가 홀 수인 경우 중심 제어점에 축에 위치하게 됩니다.

▷  Periodic 커브는 커브의 Seam이 중심 근처에 놓이게 하여 명령을 사용하세요.

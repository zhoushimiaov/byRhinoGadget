ExportEachLayer

 ExportEachLayer : Layer기준으로 지정한 확장자로 개체를 자동Export합니다.

Steps

1.  ExportEachLayer 실행

2.  Export할 확장자 선택

3.  저장위치 선택

4.  Export 할 Layer 선택

5.  이름 입력하고 확인

 

 

 

Note

▷  모델링 데이터를 파트별로 저장하여 전달할 시 사용하면 편리합니다.

PipeSmooth

 PipeSmooth : 대상 커브 기준 지름이 변형되는 부드러운 형상의 파이프 형성합니다.

Steps

1.  PipeSmooth 실행

2.  대상 커브 선택

3.  커브 위에 파이프의 지름 설정 (다중선택 가능)

4.  파이프 끝 Tangent유지 여부 선택

 

  

Option

▷  Diameter
파이프 크기 원지름으로 설정

▷  Circumference
파이프 크기 원주로 설정

▷  Area
파이프 크기 원의 영역으로 설정

▷  Tangent
파이프 끝 Tangent유지 여부 설정

Note

▷  유기적인 형태의 파이프를 만들기 용이합니다.

Example

▷  PipeSmooth와 Pipe모델 생성 결과 곡률 비교

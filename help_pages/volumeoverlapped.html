VolumeOverlapped

 VolumeOverlapped : 중첩된 부분을 불린하지 않고 근사값의 부피를 계산합니다. 불린하기 어려운 개체들의 부피 산출에 활용할 수 있습니다.

Steps

1.  VolumeOverlapped 실행

2.  중첩된 개체들 선택

3.  확인 간격 설정

4.  명령 프롬프트에서 Yes 선택

 

 

Note

▷  개체들의 단면적 기준으로 부피를 계산합니다.

▷  확인 간격을 작게 설정하면 더 정확한 근사치의 부피를 계산합니다.

▷  Brep, Mesh, SubD개체를 계산에 사용할 수 있습니다.

RebuildCrvCountByLength

 RebuildCrvCountByLength : 커브를 제어점 개수나 간격 기준으로 Rebuild합니다.

Steps

1.  RebuildCrvCountByLength 실행

2.  대상 커브 선택

3.  옵션 설정 후 완료

 

   

 

Option

▷  Point Counts
컨트롤 포인트 개수로 커브 재생성

▷  Length
길이로 컨트롤 포인트 간격이 설정된 커브 재생성

▷  Degree
커브의 차수 설정

▷  Delete Input

변환 전 커브 삭제

▷  Create new object on current layer

활성 레이어에 개체 등록

▷  Preserve end tangent directions

커브 가장자리 곡률 유지

Note

▷  역 설계 시 메시에 투영된 Polyline을 일정한 간격의 원하는 차수의 커브로 Rebuild하는데 효과적입니다.

▷  복잡한 커브를 Split하여 Rebuild 하지 않아도 원하는 모양을 유지하며 제어점을 효과적으로 줄일 수 있습니다.

ImportFilesinFolder

 ImportFilesinFolder : 지정한 폴더의 다수의 파일을 자동으로 Import 합니다.

Steps

1.  ImportFilesinFolder 실행

2.  Import할 폴더 선택

3.  옵션 설정 후 확인

 

   

 

Option

▷  Align
파일을 정렬

▷  AddNameDot
파일 이름을 도트에 표시

Note

▷  작업 폴더 내 파일들 모두를 Import하여 확인할 때 편리합니다.

▷  라이노에서 Import 가능한 확장자 파일은 모두 가능합니다.

TransformObjects

 TransformObjects : 고용량의 메시 데이터 등 이동/회전, Mirror 옵션으로 스캔데이터 대칭 설정 시 활용합니다.

Steps

1.  TransformObjects 실행

2.  이동할 개체 선택

3.  Move 기준점에서 목표점을 클릭하여 이동하거나 XYZ치수를 기입하여 이동

4.  Rotate 설정 축 기준으로 회전하거나 2개 또는 3개 점 기준으로 orient

5.  Mirror 대칭형태의 메시 데이터를 설정 축 기준으로 복사

6.  Clipping 개체의 서피스를 기준 축을 설정하여 확인

 

 

 

Option

▷  Move 이동
X, Y, Z축의 각 이동 거리 입력 또는 상하 화살표 선택으로 입력

•     Increment
X, Y, Z축 증감 기본단위 설정

•     Form To Pts
첫번째 점 마지막점 선택 기준으로 이동

▷  Rotate 회전
X, Y, Z축의 각 회전 각도에 입력 또는 상하 화살표 선택으로 개체의 회전

•     Increment
X, Y, Z축 증감 기본단위 설정

•     Align 2Pts
각 2개의 라인 설정으로 개체 회전
회전의 기준이 되는 첫번째 라인, 회전의 각도에 따라 임의로 두번째 라인 설정

•     3Pts
시작점의 기준으로 첫번째 점은 개체의 기준, 두번째 점은 회전각도 설정

▷  Mirror 대칭
두개의 각 축의 기준으로 개체의 대칭 (네모박스 선택으로 미리보기 가능)

•     Color
대칭되는 색상 변경(색상변경, 스포이트, 복사, 붙여넣기)

•     Axis
XY, XZ, YZ 축 기준으로 개체 대칭 가능

▷  Clipping 절단 뷰
두개의 각 축의 기준으로 개체의 절단 뷰 (네모박스 선택으로 미리보기 가능)

•     Plane
XY, XZ, YZ 축 기준으로 개체 절단 뷰 확인 가능

▷  Undo
되돌리기

▷  Redo
재실행

▷  Reset
초기화

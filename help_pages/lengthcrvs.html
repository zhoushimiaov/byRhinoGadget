LengthCrvs

 LengthCrvs : 선택된 모든 커브들의 Length를 표시합니다.

Steps

1.  LengthCrvs 실행

2.  옵션 설정

3.  커브 선택

 

 

Option

▷  Type

•     Dot
도트에 치수를 표시

•     Text
치수를 텍스트로 표시

∙      Text Height – 텍스트의 크기를 설정

∙      Font – 텍스트의 글꼴 설정

•     AlignedDim
끝점 기준의 치수를 표시

▷  Value

•     Length
커브의 길이를 표시

•     EndDistance
커브의 끝점 기준 거리 값을 표시

▷  nDigits

수치의 소수점 자리 설정

ex) nDigits = 1 / 0.1
ex) nDigits = 2 / 0.01

AddLayouts

 AddLayouts : 여러 레이아웃 한번에 추가 가능합니다.

Steps

1.  AddLayouts 실행

2.  레이아웃에 추가할 도면 프레임 선택

3.  레이아웃 크기 선택

 

  

Option

▷  A3_landscape
A3_가로방향의 대지

▷  A3_portrait
A3_세로방향의 대지

▷  A4_landscape
A4_가로방향의 대지

▷  A4_portrait
A4 세로방향의 대지

Note

▷  라이노 하단 뷰포트 탭에 개체 선택 따라 레이어 탭 생성합니다.

▷  PDF로 여러 장의 도면을 동시 출력할 때 편리합니다.

▷  Layouts 명령어 실행 시 AddLayouts로 만들어진 레이아웃 페이지 관리 가능합니다.

▷  대형 크기의 도면 또는 여러 장의 도면을 하나의 파일 안에서 프린트 출력할 경우 명령어로 출력 가능한 크기(A4, A3)로 각 레이어 분할합니다.

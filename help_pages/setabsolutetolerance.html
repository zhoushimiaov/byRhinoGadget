SetAbsoluteTolerance

 SetAbsoluteTolerance : 절대공차를 빠르게 변경합니다.

Steps

1.  SetAbsoluteTolerance 실행

2.  명령어 창에서 변경할 절대공차 입력

Note

▷  Rhino Options안에 Units 항목 AbsoluteTolerance변경합니다.

▷  절대공차가 계산에 영향을 주는 명령어 (FlowAlongSrf 등) 사용 시 공차 값을 낮춰서 실행할 때 빠르고 비교적 구성이 간결한 결과 도출 가능합니다.

▷  Curvature 이상의 곡률 유지 시 낮은 AbsoluteTolerance으로 생성한 개체 join가능, 이동할 점의 수가 적기 때문에 추후 점 편집에 용이합니다.

SetPtLinear3D

 SetPtLinear3D : 제어점들을 일직선 정렬합니다.

Steps

1.  서피스의 제어점 활성화

2.  SetPtLinear3D 실행

3.  정렬할 제어점들 선택

4.  직선의 두 기준점 입력

 

  

Note

▷  제어점을 원하는 방향으로 정렬할 때 사용할 수 있어 특정 제어점만 G1(Tangency) 정렬하거나 직선 형상으로 제어점 편집 시에 활용합니다.

PolylineSplit2Crvs

 PolylineSplit2Crvs : Polyline형상을 최대한 유지한 곡선으로 변환합니다.

Steps

1.  PolylineSplit2Crvs 실행

2.  대상 커브 선택

3.  옵션 선택 후 완료

 

  

 

Option

▷  Main Option

•     Angle Limit
선 연장선을 원래 커브에 접하게 생성

•     Increment
기존 커브에 접하게 호 연장선을 생성

•     Delete Input
기존 커브와 곡률 연속성을 갖는 매끄러운 커브 연장선을 생성

▷  Output

•     Interpolate
Degree : Interpolate 커브로 바꾸고 차수 변경

•     Rebuild
Point counts : 입력한 제어점 개수로 Rebuild

Degree : 입력한 차수로 커브를 차수변경

•     Refit
Tolerance : 입력한 수치로 Tolerance 변경

Degree : 입력한 차수로 커브를 차수변경

Note

▷  다양한 옵션을 통해 Polyline을 편집하는데 용이합니다.

▷  명령어 Squish와 같이 사용 시 Polyline으로 형성된 커브를 옵션 값을 설정하여 형태 변화 없이 3차수 커브로 변경 가능합니다.

WeightDensity

 WeightDensity : 재질 별 밀도 값을 편집 저장합니다.

Step

1.  WeightDensity 실행

2.  재질을 추가 후 밀도 값 설정

 

 

Note

▷  재질(밀도)라이브러리 생성 관리하여 WeigntSolid, WeightOverlapped에서 밀도 선택 시 각 라이브러리에서 사용 가능합니다.

▷  재료 밀도 검색 정리, 여러 밀도 동시 삭제 편집 가능합니다.

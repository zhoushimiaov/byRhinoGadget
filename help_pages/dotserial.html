DotSerial

 DotSerial : 순차 번호로 Dot을 생성합니다.

Steps

1.  명령어 DotSerial 실행 후

2.  숫자 앞에 적용될 접두어 입력 또는 미 입력

3.  필요한 위치에 Dot 배치

 

 

Note

▷  접두어 입력 시 ‘접두어+숫자’ 로 표기됩니다.

▷  접두어 미 입력 시 ‘숫자’ 로 표기됩니다.

▷  이전에 표기된 숫자가 있을 시 연결되어 표기됩니다.

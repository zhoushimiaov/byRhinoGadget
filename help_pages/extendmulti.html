ExtendMulti

 ExtendMulti : 여러 개의 커브를 선택된 Boundary Object까지 일률적으로 연장합니다.

Step

1.  ExtendMulti 실행

2.  옵션 설정

3.  Boundary 개체 선택 (복수 선택 가능)

4.  연장시킬 커브 선택 (복수 선택 가능)

 

 

Option

▷  Type

•     Line
선 연장선을 원래 커브에 접하게 생성

•     Arc
기존 커브에 접하게 호 연장선을 생성

•     Smooth
기존 커브와 곡률 연속성을 갖는 매끄러운 커브 연장선을 생성

Note

▷  곡선, 직선 없이 실행 가능하며, Boundary Object 역시 커브, 서피스, 솔리드 관계없이 실행 가능합니다.

▷  한번의 명령어 실행으로 선택한 모든 커브에 Extend를 실행합니다.

▷  연장할 커브의 진행 방향에 Boundary 개체가 위치하는 경우에만 실행됩니다.

mkGraphics

 mkGraphics : 선택된 커브를 개체에 투영하고 투영된 개체를 복사하여 분할된 서피스를 생성합니다.

Steps

1.  mkGraphics 실행

2.  서피스를 생성할 커브 선택

3.  서피스를 생성할 기준 서피스 선택

4.  옵션 선택 후 적용

 

  

Option

▷  Height
돌출 높이 설정

▷  Direction
돌출 각도 및 방향 설정

▷  Filp
버튼의 생성 방향 뒤집기

Note

▷  인쇄되어 표현된 부분을 만들 때 편리합니다.

▷  형상이 될 커브는 닫힌 상태이여야 합니다.

▷  기준 서피스와 간격, 방향 조절 가능합니다.

FitCrvLength

 FitCrvLength : 커브의 길이를 끝점을 유지한 채 지정한 길이가 되도록 수정합니다.

Steps

1.  커브준비

2.  FitCrvLength 실행

3.  길이 값 입력

 

  

Note

▷  2D패턴, 의류패턴 등을 위한 패턴 작업 시 전개도의 곡선 커브의 길이를 정확히 편집할 때 사용하면 편리합니다.

▷  명령어 실행 시 나타나는 문구 Target curve length (Distance between ends is ***) 여기서의 길이 값 보다 적게 설정할 시 1차수 커브로 변경되며, 길이를 설정한 값으로 감소됩니다.

▷  끝점 2개의 간격이 축소 가능한 최소길이 입니다.

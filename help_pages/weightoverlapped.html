WeightOverlapped

 WeightOverlapped : 중첩된 부분을 합집합으로 계산한 여러 개체의 무게 값을 나타냅니다.

Steps

1.  WeightOverlapped 실행

2.  대상 개체 선택

3.  밀도 설정

4.  확인 간격 입력

5.  명령 프롬프트에서 확인

 

   

Note

▷  다중 개체의 무게 값을 더한 값이 필요할 때 사용합니다.

▷  확인 간격을 작게 설정하면 더 정확한 수치가 도출됩니다.

▷  WeightDensity에 기본 값으로 설정되어 있는 재질이나 새로 추가된 재질을 기준으로 무게 값을 표시합니다.

▷  SubD개체에서 사용 가능합니다.

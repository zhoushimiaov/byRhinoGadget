StepExtrude

 StepExtrude : 여러 개의 커브를 설정 높이로 계단 형태의 지오메트리를 생성합니다.

Steps

1.  StepExtrude 실행

2.  가장 자리 커브 선택

3.  등고 커브 선택 (다중선택 가능)

4.  옵션설정

5.  가장 하단으로 설정할 서피스 선택 (다중선택 가능)

 

   

Option

▷  Height
커브 간 단의 높이 설정

▷  Type
Extrude 솔리드 생성, Move 서피스 생성

▷  BooleanUnion
단계 솔리드 하나로 생성

▷  MergeFaces
다중 선택된 기준 서피스 하나로 생성

Note

▷  등고 커브 다중선택 가능합니다.

▷  기준 서피스 다중선택 가능합니다.
